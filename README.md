# SmartPark 🚗

Sistema inteligente de gestión de parqueaderos para conjuntos residenciales.

## Descripción del Proyecto

SmartPark es una solución completa diseñada para facilitar la administración y gestión de espacios de parqueadero en conjuntos residenciales. El sistema permite monitorear, controlar y optimizar el uso de espacios disponibles, brindando una experiencia mejorada tanto para residentes como para administradores.

## Características Principales

- 📊 **Gestión de Espacios**: Monitoreo en tiempo real de espacios disponibles
- 👥 **Control de Acceso**: Sistema de autorización y autenticación para residentes
- 📱 **Interfaz Responsiva**: Aplicación web moderna y fácil de usar
- 🔐 **Seguridad**: Autenticación segura y protección de datos
- 📈 **Reportes**: Generación de estadísticas de uso y ocupación

## Stack Tecnológico

- **Frontend**: TypeScript (50.4%), HTML (23.7%), SCSS (21.2%)
- **Backend**: Kotlin (4.4%)
- **DevOps**: Docker (0.3%)
